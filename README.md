# Mikhail Kirs — Portfolio

Static portfolio website for Mikhail Kirs, a London, Ontario–based Video Content Producer focused on Personal Brand Content, Local Business Storytelling, long-form city work and visual communication.

## Pages

- `index.html` — home, selected work, services, about and contact
- `project-mayoral.html` — municipal campaign content case study
- `project-forest-city.html` — Forest City Spotlight case study
- `project-city-storytelling.html` — London (UK) and Belgrade long-form city work

## Technology

Semantic HTML and responsive CSS with no JavaScript dependency in the current build. The site is prepared for direct deployment from this repository through Vercel.

## Media status

The current preview still uses graphic placeholders while final authorized portrait photography, city photography, project stills and video links are selected. The layout is designed so real media can replace the placeholders without changing the overall editorial direction.

## Source-of-truth rule

Professional positioning, project responsibilities, credits and results are verified in the private `DariaKirs/Mikhail-Work-Life` workspace before they are stated publicly here. Private research, internal documents and sensitive material must not be copied into this public repository.
