# Mikhail Kirs — Portfolio

Static portfolio website for Mikhail Kirs, a London, Ontario–based Video Content Producer focused on Personal Brand Content, Local Business Storytelling and visual communication.

## Pages

- `index.html` — home, selected work, services, about and contact
- `project-mayoral.html` — Mayoral Campaign Content case study
- `project-forest-city.html` — Forest City Spotlight case study

## Technology

Semantic HTML and responsive CSS. The site is prepared for direct deployment from this repository through Vercel.

## Media status

The current preview uses graphic placeholders while the final authorized portrait, city photography and project stills are selected. The page structure and image crops are already prepared in `assets/images/`.
